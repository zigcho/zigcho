# profile settings finally line up

the flag picker is in the profile tab, straight under the accent choices, and uses actual flags instead of a country-code box. the preview now shows the selected flag and the rest of the profile details beside it, including roles and setup tags. switching the flag off in privacy hides it from the preview too.

picture and banner upload controls now use the same upload and remove buttons. the hidden file inputs no longer show up as duplicate controls, and the buttons show when an upload is in progress. banners still get fitted automatically when they are uploaded.

the old footer called lazer alpha even though that stopped being true. it now says stable + lazer live.
